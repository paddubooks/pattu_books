# Project overview

Pattu Books remains the static homepage and book catalogue. Pattu Learn adds a browser-local Maths learning area for ages 4–6, with the Kindergarten collection and English content. The collection includes advanced counting ranges inherited from the source; adults should select by readiness.

The source inventory contains 52 topics, 369 mapped reference skills, 705 activities (549 core and 156 extensions), and 8,460 top-level question sets. Nested cards are not counted as extra sets. There are 20,075 source SVG files, 705 source student PNGs and 101 local WAV recordings. Imported examples use existing local question assets. Current import/validation reports provide computed totals.

Features include the full searchable catalogue, difficulty/extension filters, topic pages, twelve source interaction modes, worked-example views, saved sessions, completion/continue controls, selected-topic offline downloads and persistent links to Books. No accounts, API or learning backend are introduced.

This is an integrated local implementation, not a public deployment. Test reports and known issues describe verification limits; source package claims are not treated as new integration test results.
